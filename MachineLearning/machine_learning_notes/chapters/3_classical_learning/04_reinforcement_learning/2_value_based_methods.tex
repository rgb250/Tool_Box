\subsection{Purpose}
Learn $V^{\pi}$ or $Q^{*}$ from sampled experience $(s,a,r,s')$, and derive the policy from
the values.

\subsection{Monte Carlo and Temporal Difference}
\paragraph{Monte Carlo} Wait for the end of the episode, then move $V(s_{t})$ towards the
observed return $G_{t}$. Unbiased, but high variance, and it needs complete episodes.

\paragraph{Temporal difference (TD(0))} Update after each step, using the current estimate
of the next state instead of the full return (\emph{bootstrapping}):
\begin{center}
    \frB{$V(s_{t})\leftarrow V(s_{t})+\alpha\,\delta_{t},\qquad
    \delta_{t}=r_{t+1}+\gamma V(s_{t+1})-V(s_{t})$}
\end{center}
$\delta_{t}$ is the \textbf{TD error}. Compared to Monte Carlo, TD has lower variance and
learns online, but is biased because $V(s_{t+1})$ is itself an estimate.

\subsection{SARSA and Q-learning}
\begin{itemize}
    \item \textbf{SARSA} (\uB{on-policy}) uses the action $a_{t+1}$ actually chosen by the
        current policy:\\
        $Q(s_{t},a_{t})\leftarrow Q(s_{t},a_{t})+\alpha\left[r_{t+1}+\gamma Q(s_{t+1},
        a_{t+1})-Q(s_{t},a_{t})\right]$
    \item \textbf{Q-learning} (\uB{off-policy}) uses the best next action, whatever was
        done:
        \begin{center}
            \frB{$Q(s_{t},a_{t})\leftarrow Q(s_{t},a_{t})+\alpha\left[r_{t+1}+\gamma
            \max_{a'}Q(s_{t+1},a')-Q(s_{t},a_{t})\right]$}
        \end{center}
        It is the sampled version of the Bellman optimality equation, and it can learn
        the optimal policy while behaving with an $\varepsilon$-greedy one.
\end{itemize}
\tB{On-policy} methods learn about the policy that generates the data, \tB{off-policy}
methods can learn from data generated by another policy.

\paragraph{Function approximation} A table with one entry per $(s,a)$ is impossible for
large state spaces. \textbf{Deep Q-networks} (DQN) approximate $Q_{\bm{\theta}}(s,a)$ by a
neural network, trained by minimizing the squared TD error. Two ingredients stabilize it:
an \emph{experience replay} buffer (random past transitions break the correlation between
consecutive samples) and a slowly updated \emph{target network} for the bootstrapped term.

\paragraph{Weaknesses}
\begin{itemize}
    \item they need a $\max$ or an $\argmax$ over the actions, which is impractical for huge
        or continuous action spaces (for a language model, an action is a token among
        $V\approx10^{5}$, and a whole answer is a sequence of them);
    \item bootstrapping with function approximation and off-policy data can be unstable.
\end{itemize}
