\subsection{Introduction}
Avoid treating parameters as random variables.
The notion of variation across repeated trials forms the basis for modelling
uncertainity.


\subsection{Hypothesis Testing}
In frequentist statistics, probabilities represent frequencies of events across repeated trials.
\begin{itemize}
    \item \textbf{Null hypothesis} $H_0$: default assumption (e.g., no effect, $\theta = \theta_0$)
    \item \textbf{Alternative hypothesis} $H_1$: what we want to test (e.g., $\theta \neq \theta_0$)
    \item \textbf{Test statistic} $T = T(\mathcal{D})$: function of data used for decision
    \item \textbf{Critical region} $\mathcal{C}_\alpha$: values of $T$ leading to rejection of $H_0$
\end{itemize}
Decision rule: reject $H_0$ if $T \in \mathcal{C}_\alpha$.

\subsection{\emph{p-value}}
The \tB{probability of observing a test statistic as extreme or more extreme than the
observed value, assuming $H_0$ is true}:
$$p\text{-value} \triangleq \mathbb{P}(T \geq t_{obs} \mid H_0)$$
For two-sided tests: $p\text{-value} = \mathbb{P}(|T| \geq |t_{obs}| \mid H_0)$.\\
Decision rule:
$$\begin{cases}
    \text{Reject } H_0 & \text{if } p\text{-value} < \alpha \\
    \text{Fail to reject } H_0 & \text{if } p\text{-value} \geq \alpha
\end{cases}$$
where $\alpha$ is the \textbf{significance level} (typically $\alpha = 0.05$).

\subsection{Confidence intervals}
A $(1-\alpha)$ \textbf{confidence interval} for parameter $\theta$ is an interval
$[\hat{\theta}_L, \hat{\theta}_U]$ such that:
$$\mathbb{P}(\hat{\theta}_L \leq \theta \leq \hat{\theta}_U) = 1 - \alpha$$
For a sample mean with known variance: $\text{CI}_{1-\alpha} = \bar{x} \pm z_{\alpha/2} \dfrac{\sigma}{\sqrt{n}}$\\
For unknown variance (using $t$-distribution): $\text{CI}_{1-\alpha} = \bar{x} \pm t_{\alpha/2, n-1} \dfrac{s}{\sqrt{n}}$\\[0.5em]
\textbf{Frequentist interpretation}: \tB{if we repeat the experiment many times, $(1-\alpha)\%$
of the constructed intervals will contain the true parameter $\theta$}.\\[0.5em]
\textbf{Link to hypothesis testing}: if the $(1-\alpha)$ CI for $\theta$ does not include $\theta_0$,
then we reject $H_0: \theta = \theta_0$ at significance level $\alpha$.

\subsection{Multiple comparisons}
Running $k$ tests increases the \textbf{family-wise error rate} (FWER):
$$\mathbb{P}(\text{at least one false positive}) = 1 - (1-\alpha)^k \approx k\alpha \text{ for small } \alpha$$
\textbf{Bonferroni correction}: controls FWER by adjusting either:
\begin{itemize}
	\item the threshold: $\alpha_{adj} = \dfrac{\alpha}{k}$, or
    \item the p-values: $p_{adj} = \min(k \times p_{values}, 1)$
\end{itemize}
Reject $H_0^{(i)}$ if $p_i < \alpha_{adj}$ (equivalently, if $p_{adj,i} < \alpha$).\\[0.5em]
\textbf{Note}: Bonferroni is conservative. Alternatives include Holm-Bonferroni (less conservative)
and False Discovery Rate (FDR) control for large-scale testing.

\subsection{Effect size}
The \textbf{effect size} measures the \tB{magnitude of a phenomenon independently of sample size}.
Unlike p-values, effect sizes indicate practical significance.
\begin{itemize}
    \item \textbf{Cohen's $d$} (difference between means):
        $d = \dfrac{\bar{x}_1 - \bar{x}_2}{s_{pooled}}$ where
        $s_{pooled} = \sqrt{\dfrac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}}$
    \item \textbf{Pearson's $r$} (correlation): $r \in [-1, 1]$
    \item \textbf{$\eta^2$, $\omega^2$} (variance explained in ANOVA)
\end{itemize}

\subsection{Sample size}
Sample size $n$ is related to \textbf{effect size} $d$, \textbf{power} $(1-\beta)$, and
\textbf{significance level} $\alpha$ through:
$$n \propto \dfrac{(z_{1-\alpha/2} + z_{1-\beta})^2}{d^2}$$
For a two-sample $t$-test (per group):
$$n = 2\left(\dfrac{z_{1-\alpha/2} + z_{1-\beta}}{d}\right)^2$$
\textbf{Key relationships}:
\begin{itemize}
    \item Larger effect size $d$ $\Rightarrow$ smaller $n$ needed
    \item Higher power $(1-\beta)$ $\Rightarrow$ larger $n$ needed
    \item Smaller $\alpha$ (stricter significance) $\Rightarrow$ larger $n$ needed
\end{itemize}
\textbf{Trade-off}: with large $n$, even tiny (practically irrelevant) effects become
statistically significant. Always report effect sizes alongside p-values.
